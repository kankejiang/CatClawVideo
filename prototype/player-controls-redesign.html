猫爪影视 · 播放控件重设计

目标：把播放区域的控制层做成「一眼看懂、遥控器好使、三端统一」的一套控件。
先出模板，确认方向后再改 VideoPlayerPage / WatchPage 的 XAML。

一、现状问题（基于你的截图）

待解决

① 进度条几乎看不见

进度轴太细、对比度低，45 分钟的片子只能靠猜位置；已缓冲区间也没有表达。

② 控件语义混在一起

左侧 ‹ › 是切集、右侧 «« »» 是 ±10s，图标形态相近却行为不同，容易误点。

③ 中央键与底栏键重复

同一个「暂停」出现两次，信息冗余；底栏空间本可以留给更有用的入口（倍速 / 选集 / 音轨）。

④ 时间与全屏被挤到边缘

时间贴左、全屏贴右，视觉上不成组；遥控器焦点也没有明确落点。

三、方案 B · 悬浮双行面板

功能最全

五、三套方案共用的改进点

项目做法
进度轴 默认 5px / 悬停与焦点 9~11px；分三层：底轨 → 已缓冲（白 34%）→ 已播放（紫青渐变 + 发光）；拖拽时显示时间气泡预览。
切集 vs 快进 用位置和形态双重区分：切集是单箭头放在控制条两端（A 方案另有大面积边缘热区），快进快退是双箭头 + 10 角标，成组放在右侧。
去重复 中央大键只在暂停/无操作时出现；底部播放键是常驻主键，两者互斥显示（不再同时出现两个「暂停」）。
时间显示 时间紧贴进度轴两端（不再贴屏幕边缘），等宽数字避免跳动；当前时间加粗白色、总时长次级色。
自动隐藏 鼠标移动 / 按键 / 焦点变化即重置计时；焦点在控件上时禁止隐藏（遥控器场景必须，否则焦点会消失）。
关于遥控器：播放页需要新增 IRemoteKeyHandler 实现 —— 焦点分层「顶栏 → 进度轴 → 按钮排」，←→ 在进度轴上 ±10s、在按钮排内横向移动， OK 执行，Back 逐层退回后退出播放。
这与刚做完的设置页 / 首页焦点体系是同一套（RemoteKeyRouter），可复用。
