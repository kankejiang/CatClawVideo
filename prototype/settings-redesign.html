五、按键映射（三端统一）

按键行为
↑ ↓栏内垂直移动（顺序 = 视觉顺序，无跳跃）
← →① 调值（步进 / 开关）② 侧栏 ↔ 内容区 换栏 ③ 顶栏 tab 间移动
OK / Enter进入子页 / 切换开关 / 提交
Back / Esc返回上一级；设置根页则退出设置
落地方式：新建可聚焦行控件（内部用 VisualStateManager 定义 Normal / Focused / PointerOver 三态）， 三端共享同一份 XAML；平台层只补方向键映射。
当前仓库尚无任何焦点基础设施（KeyEvent / Focusable / VisualState 全为 0 命中），需一并新建。
不做竖屏：本页只保证横屏；Android 已是 SensorLandscape 基准，天然满足。
