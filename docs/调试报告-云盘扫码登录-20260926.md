### 问题 3：ART guest 链路 UI 失联
- `home-debug.log` 12:42:16：`NullPointerException: getPackageManager() on a null object reference at com.github.catvod.spider.merge.cn.B`

### 问题 4/5：二维码过期与会话卡死
- 13:14:20 首次 `ui-dialog`（网盘列表 rows）；13:14:23 二维码 `ui-dialog qr=175x175`（106KB 像素矩阵）+ toast「需使用夸克浏览器APP扫码登录」。
- 之后 `uop.quark.cn` 每秒一次 TLS 轮询，`spUtils.quark_ck` 始终未落库、无 `ui-dismiss` → 判定扫码/确认未在有效期内完成。
- 13:20 起二次登入：`[ui] 视图树 … qr=无`（`AlertDialog.java:55-56` 产出），即 **jar 根本没构建带 ImageView 的对话框**；同时「清除成功」toast 每 7 秒自动重复。
- 研究员代码侧核查（研究员子代理结论）：
  - 桩侧排除三类嫌疑：`Dialog.show` 无条件上行（`Dialog.java:46-59`）；`PENDING` 仅 seq→回调映射且 dismiss 正常清理（`UiBridge.java:36`）；`Bitmap.createBitmap` 无静态状态（`Bitmap.java:70-77`）。
  - `SystemClock.java:18-22` 桩注释**记载过同款症状**：「差值算术判已过期 ⇒ 轮询一次都不发，只剩每 7 秒重弹一次『需扫码登录』」。
  - 根因排序：① jar 扫码会话线程未随码过期退出、静态标志未复位（jar 混淆不可改）；② 慢速节拍残留放大时间窗口错乱；③ Canvas/Bitmap 像素层已基本排除。
  - **桌面端渲染链路无问题**——13:14 首次成功即为证明。

- `spider-ui-last.json`、`spider-ui` 诊断通道工作正常，是排查此类问题的有效抓手。

## 三、解决方案

### A. 立即可用（用户操作）
1. **重启应用回收桥 JVM**——清掉 jar 内卡死的会话线程（研究员的验证/绕过方法：重启后首点即弹码，即钉死状态残留在 jar 进程内）。
2. **一气呵成完成扫码**：登入 → 点网盘行 → 码一出现立刻用夸克 APP 扫 → 手机上点「确认登录」，全程 ≤ 1 分钟（码有效期约 2 分钟）。
3. 启动命令（含本次全部环境变量）：
   ```powershell
   $env:DOTNET_ROOT    = 'D:\Code\CatClawVideo\.dotnet'
   $env:CATCLAW_NO_ART = '1'   # 桌面端暂用宿主 JRE 桥，绕开 ART guest 的 UI 失联
   & 'D:\Code\CatClawVideo\CatClawVideo.Maui\bin\Debug\net11.0-windows10.0.26100.0\win-x64\CatClawVideo.Maui.exe'
   ```
