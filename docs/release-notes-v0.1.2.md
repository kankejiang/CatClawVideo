猫爪影视 v0.1.2 —— 本次更新以 **遥控器（电视遥控 / 键盘方向键）焦点体系** 为主线：把「按了没反应」「焦点跑到看不见的地方」「焦点环看不出来」这一整类问题从根上理清，并补齐播放页的控制能力与换源入口；同时包含磁力加载提速、缓冲指示、搜索页版面重构等多项改进。

> 自 v0.1.1（2026-09-18）以来共 **33 个提交**，跨度 09-18 ~ 09-19。

---

## 一、焦点体系：从「各页各写一套」到「统一路由 + 统一视觉」

### 1. 补上三处完全没接按键的页面
- **历史 / 收藏**：此前只实现 `ITabView`，没接 `IRemoteKeyHandler` —— 方向键在顶栏层就被挡掉，按键根本进不了页面（「完全没反应」）。
- **播放页（WatchPage）**：同上。现在有**四个焦点区**：控制条 / 收藏·换源·分享 / 选集栏 / 顶栏（返回·线路）。
- **搜索页顶栏**：返回按钮原先不在焦点图里，只能靠 `Back` 退出；现在键盘顶行 `↑` 即达。

### 2. 播放页可遥控操作（新增）
- 控制条按钮间 `←→` 移动、`OK` 触发；**隐藏的按钮自动排除在焦点序列外**（如全屏播放页关掉「选集」时不残留死焦点）。
- 选集栏：方向键选片、跨页**自动翻页**、`OK` 切集；「正在播放」的底色与「焦点」的描边互不覆盖，两格能同时区分。
- `Back` 先退焦点、再按一次才返回上一页（防误触退出播放）。
- 为支持遥控，给 `IconButton` 加了 `IsFocused` 与 `Invoke()`（走的就是鼠标点击那条委托，行为完全一致）。

### 3. 焦点视觉：一处定义，四处共用
- 焦点环原先各页各抄一份，改一处漏几处。现抽成 `Styles.xaml` 的 `PosterCardStyle` + `PosterFocusRingStyle`，**首页 / 历史 / 收藏 / 搜索-继续观看**共用。
- 修掉三个「焦点看不清」的真因：
  - **描边被海报图盖住** → 焦点环改为画在图片**之上**的独立元素；
  - **描边骑在路径上、外侧一半被卡片自身裁掉** → 环与卡片平级，只受格子边界约束；
  - **卡片比格子宽、右侧被 item 容器裁掉** → 布局助手按真实间距回推格宽，放不下就减列。
- 顺带记录一个坑：**本项目 `Style.Triggers` 不生效**（DataTrigger 静默失效，页面不报错）—— 焦点相关一律用直接绑定。

### 4. 焦点归属规则修正
- **启动停在顶栏「首页」**（原先被首页的「切换源」抢走）。
- **用户选定某个 tab 后，焦点直接进内容区**（原先还赖在顶栏，按 `←→` 在换 tab、`OK` 又切走，观感是「选了历史却回到首页」）。
- **数据未加载完也能接住焦点**：切 tab 时列表是异步加载的，焦点请求先「记账」，列表到齐自动补点亮（修「第一次按没反应、第二次才有焦点」）。
- **切 tab 时让旧页交出焦点并出栈**：隐藏页不再吃按键。
- `MainPage` 按键入口改挂 **隧道路由（`PreviewKeyDownEvent`）**：冒泡阶段设置 `e.Handled` 太晚，元素级处理已经跑完 —— 这是「回车被顶栏 tab 当成点击、又切回首页」的根因。同时方向键一律吃掉，避免 WinUI 原生焦点框叠在我们自己的环上（白框）。

## 二、播放页：换源

- 信息区新增 **`换源`** 按钮（收藏左侧）：拿当前片名直接跳搜索页（`search?q=`）做跨站搜索，结果里挑别的站点即用该站点播放；`Back` 可退回原站点，试错不丢进度。
- 换源实现从「自建跨站搜索 + 选站点弹窗」改为**复用搜索页**（净减约 90 行）—— 搜索页本就有跨站并行搜索、站点筛选、分站显示。

## 三、搜索页

- **带关键词进入时结果被输入态盖掉**：`ShowInputPanels` 会把结果隐藏、状态置回输入态，导致「搜了但看不到结果」（收藏页「跨源搜回该片」同样受影响）—— 已修。
- **进度可见**：搜索中显示 `已完成 n/N 个站点`（此前该计数统计了却从没用上）。
- **不再白等**：原先固定等待 `12s + 20s`，即使结果早已到齐也要停满 —— 现在是「全回来就提前结束」。
- 焦点：结果态下 `FocusContent` 交给结果墙（原先写死给键盘，要再按一次才到海报）。

## 四、首页

- 顶栏 `↓` 只做一件事：进分类 chips（不再先经「切换源」）。
- 最右 chip `→` 上到「切换源」；「切换源」`←` 退回最右 chip（两边互为出口）。
- 顶栏焦点序列补上**搜索入口**（原先只能鼠标点）。
- 分类 chip 数量多时，焦点自动横向滚动跟随。

## 五、数据源弹窗（请选择首页数据源）

- **接入遥控**：打开时焦点落在「当前正在用的站点」，两列栅格内移动，第一行 `↑` 到右上角 ✕，`OK` 选中、`Back` 关闭；站点多时自动滚动跟随。
- 弹窗期间**独占按键**（原先按键会漏到背后被遮住的首页去动焦点）——「弹窗没有焦点、遥控器关不掉」的成因。
- 模态弹窗打开时，数字键 / `F6` 不再在背后切页。

## 六、Windows 窗口拖拽

- 拖拽区改为**整条顶栏的横向补集**：控件照常可点，而控件上下左右的空白（含页面顶部那条内边距）都能拖。
- 新增 `IWindowDragArea`：播放页这类「空白分散在控件四周」的页面由页面自管拖拽区。
  - 此前页面在 `OnAppearing` 里声明是**无效**的 —— `Shell.Navigated` 的统一下发点会因为「当前页不是主页」把拖拽区清零，这正是「播放页怎么都拖不动」的真因。
- 顶栏点击被吞的两次修复：顶栏 tab 补可命中的背景、顶栏整体下移出窗口标题栏非客户区。
- 中途一度改用 `Window.SetTitleBar`（照抄猫爪音乐），实测 `Passthrough` 对**物理鼠标**不可靠（顶栏 tab「要点好几次才有反应」），已改回 `SetDragRectangles` 方向。

## 七、Windows 磁力播放与播放器体验

### 1. 加载与起播
- **VM 预热**：消除 Windows 端 11 秒冷启动等待。
- 等种子落盘超时 **120s → 自适应 45s**：死链提前失败，不再干等两分钟。
- 探测结果落盘 `magnet-files.json`：跨启动复用，第二次打开同一部剧直接出选集。
- **流式线路加载**（`IProgressiveVodSourceProvider`）：先出选集、再逐步展开，不再等全部线路就绪才显示。

### 2. 缓冲指示（新增）
- 新增自绘圆环控件 `BufferProgressView`（百分比 + 不确定态）。
- 新增 `BufferedFrontier` / `IsBufferedPositionReliable` / `IsWaitingForData` 契约。
- 磁力路以 `QemuStreamProxy.ReaderStarving` 为权威判据（真实饥饿信号，而非虚拟的下载比例）。
- `ReaderAheadBytes`：从最慢读者到缓存前沿的**连续可播量**，替代此前虚高的「下载比例」。

### 3. 播放控制条
- 按钮改**中文文字**（上一集 / 播放 / 快进 10 秒…），`IconButton` 支持自适应宽度。
- 补接线 `SpeedRequested` / `MuteChanged`（此前无人订阅，按钮点了没反应）。
- 实现**倍速**（Windows `PlaybackRate` / Android `PlaybackParameters`）与**静音**。
- 控件条随播放区尺寸自适应缩放（手机端不再「吃掉大半个画面」）。

### 4. 下载
- 恢复磁力下载真实调用（此前是过时的硬编码提示）。
- 修导出阶段进度回调未节流导致的 **UI 卡死**。
- 下载状态与落盘**原子化** + 启动对账（救援「已下载但状态丢失」的任务）。

### 5. 全屏播放页
- 新增**选集浮层**（全屏下可选集，不必退出全屏）。
- 修播放器比例（去掉 560 固定上限）、选集栏高度跟随播放器同步。

## 八、搜索页版面（本次重构的来龙去脉）

- **三版演进**：
  1. 遥控器优先重构 —— 虚拟键盘 + 首字母联想 + 全宽结果 + 站点纵列；
  2. 全高双栏（方案 A）—— 键盘数字行 `1~0` 置顶，解掉「下方空一大片」（键盘与热词都是自然高度，`*` 行里约 400px 无人认领）；
  3. 热门搜索与继续观看合成**一个整体滚动容器**，继续观看海报墙吃掉余量。
- 键盘高度随左栏可用高度自适应（手机横屏逻辑高度仅约 360dp，写死 300 会顶破屏）。
- 修「继续观看海报被裁成一条边」（热词限行 + 卡片高按区块反推）。

## 九、设置页 / 关于页 / Android 体验

- **诊断日志**：设置页新增开关 + 查看 / 导出页（对齐猫爪音乐；文件写入 `AppPaths` 下的 `logs/debug.log`，带限流与轮转）。
- 移除「手机当解析节点」与设置页里的下载入口；新增 Windows **窗口尺寸记忆**。
- **关于页**：返回按钮移入内容区、页面不显示系统状态栏（去掉页首深色带）。
- **Android 安全区**：推入式页面（搜索 / 源配置 / 任务详情）顶栏不再压状态栏。
- 移除《饭太硬接口分析》文档（内容已失效），新增搜索页重构原型（`prototype/search-redesign-v2.html`）。

## 产物说明

| 文件 | 平台 | 说明 |
|---|---|---|
| `catclaw.video-0.1.2-Setup.exe` | Windows | 安装版（self-contained，无需另装 .NET 运行时） |
| `com.catclaw.video-Signed.apk` | Android | arm64-v8a 签名包，Android 12 (API 31) 及以上 |

> Windows 端的磁力播放需要随包的 `ThunderRuntime/`（QEMU + 内核 + initrd），安装包已包含，无需额外下载。
> **磁力播放依赖第三方迅雷引擎的可用性**；若某源起播失败，可在同剧的其他可播站点间自动换源。
