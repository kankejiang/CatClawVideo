来源：用户提供配置（接口地址 `http://www.xn--sss604efuw.cc/tv`），典型「饭太硬」生态结构。
目的：评估哪些内容可移植到猫爪影音。

## 2. spider jar 解剖结论（关键）

- MANIFEST：`Dex-Location: classes.dex` → **Android DEX**，非普通 class jar
- 仅 36KB 却含 45 个 `com.github.catvod.spider.*Guard` 类 + `DexClassLoader` 引用
  → **Guard 全是加密 stub**：真实爬虫代码运行时才解密加载（防白嫖设计）
- 含 Android API 依赖（Context/SharedPreferences/Log）

**移植含义**：直接跑通需要 ① dex→jar（已有）② 运行时 DexClassLoader 仿真
（把 stub 解密出的 dex 再转换加载，桥里尚无）③ Android stub 完备性（已有基础）。
工程量中等偏大，且对方刻意加密 → 兼容性不可控、随时可能失效。

## 3. 站点逐个评估

### 已覆盖（无需移植）
- **奥特** `csp_AueteGuard`、**新6V** `csp_SixVGuard` —— 猫爪源已原生适配 auete/xb6v
  （且新6V 实测翻页正常；奥特翻页规则待按真实结构修正——见 2026-09-12 日志）

### 高价值、建议原生适配（走猫爪源规则路线，不依赖 jar）
| 站点 | 价值 | 适配可行性 |
|---|---|---|
| 玩偶哥哥（4K弹幕） | 生态里口碑最好的 4K+弹幕聚合（网盘源） | 中——网盘聚合需账号配置（Cloud-drive.txt） |
| 盘搜/易搜（ZPan/JPan） | 网盘聚合搜索（夸克/阿里/百度/迅雷） | 高——有公开搜索 API（so.252035.xyz 等），可像 auete 一样写规则 |
| 盘她/盘他/抠搜/优汐 | 同类网盘搜索 | 同上 |
| 云盘配置 `tvfan/Cloud-drive.txt` | 上述网盘源的账号池 | 拉取解析后作为 ext 传入 |

### 需要新功能才有意义
- **直播 6 组 m3u** —— 需新增「直播」页签 + m3u 解析播放器（工程量中等，独立性强）
- **Bili 合集**（明星MV/少儿/小学/初中/高中课堂）—— 需 B 站 API 适配
- **push_agent（手机推送）** —— TVBox 专属交互，无移植意义

### 低价值
- 其余 Guard 影视站（海绵/厂长/立播/比特/糯米/文采/热播/茉莉/播客/剧圈/咕咕/巴士…）
  —— 与现有猫爪源高度同质，且都要过加密 jar，性价比低

## 4. 建议路线

1. **零成本试验**：把接口 URL 直接添加为 TVBox 订阅（现有订阅机制），实测桥对
   「DEX jar + Guard stub」的兼容性——若通，45 个站白得
2. **原生适配优先级**：易搜/盘搜（有清晰 API）> 玩偶（需网盘账号体系）
3. **直播**作为独立 feature 评估（m3u 解析 + 频道 UI + 播放，可复用现有播放器）
4. 不建议为 Guard 加密 jar 投入 DexClassLoader 仿真工程，除非第 1 步实测接近可用
