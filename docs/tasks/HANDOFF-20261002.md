## 2. P0-1 详细交接（**当前唯一卡点 ✗**）

### 2.1 已查明的完整因果链（都有实证 ✗）

```
SF 启动 → 查 mapper@4.0 ✔（非 null）→ 分配显示缓冲
  → GraphicBufferAllocator::allocate(w=1280 h=720 fmt=0x1 usage=0x1b00 ✔ 参数正确)
  → mapper 返回 rc=5 = HIDL mapper Error::NO_RESOURCES ✗
  → minigbm(cros_gralloc) 用 mesa 的 libgbm_mesa：**gbm_create_device(fd) = NULL, errno=ENOENT(2)** ✗
  → 原因：mesa 的 gbm 需要 DRI 后端 dri/<driver>_dri.so → 指向 libgallium_dri.so
     我们此前改走 ANGLE 时把 libgallium_dri.so 从包里删了 ⇒ 现在补回，但软链只建成功一个 ✗
```

**可靠判据（务必用它 ✗）**：guest 里跑 `/system/bin/gbmprobe` ✔
- 失败：`gbm_create_device(3) = 0x0  errno=2` ✗
- 成功：`gbm_create_device(3) = 0x...` 非 0 ⇒ 再看 SF 日志 `<< allocate(9) rc=0` ✔

⚠ **不要**用 `open/openat` 符号探针判断"有没有打开设备" ✗ —— 在 bionic 上**无效**（实测 0 命中 ✗）。

### 2.2 已经做完的改动（在仓库里 ✔）

## 4. 踩坑清单（我踩过的 ✗，请勿重复 ✗）

1. **C++ 成员函数的符号拦截必须带 `void *self`（隐式 `this`）** ✗ —— 漏了会导致参数错位一格 +
   把垃圾当 `this` 转发 ⇒ **野指针崩溃** ✗（我为此白追了 3 轮 ✗）。
2. **变参日志拦截要用 `__android_log_vprint(…, va_list)` 转发** ✗；用 `real(prio,tag,fmt,ap)` 调
   **变参函数**会把 `va_list` 当变参读 ⇒ `%s` 拿垃圾 ⇒ `strlen` 崩 ⇒ **是 shim 自己崩 SF** ✗。
3. **VINTF**：同一个 `<name>` 只能**一个** `<hal>` 块 ✗（多版本写同块 ✗）；framework manifest
   **不能**放到 device 路径 ✗（`system/manifest.xml` ✗）；vendor 合并体**不能**写进 system 路径 ✗
   （会与原厂片段重复 ✗）⇒ 任一处非法 ⇒ **整份 manifest EINVAL** ⇒ 所有 HAL 查找失败 ✗。
4. **`.so` 里改代码后必须重新打包并**把产物取回** ✗（我漏取回 `android-stack.tar.gz` ✗ / `mesa-gl.tar.gz` ✗ 各白跑过 ✗）。
5. **编译失败先查"重复函数定义"** ✗（历史补丁重复插入 ✗，会让你一直在跑旧 shim ✗）。
6. `PowerShell`：`.Replace(a,b,1)` **不存在** ✗；`$port:` 被当盘符 ✗；`adb shell "… | grep …"` 里的
   `|` **会被本地 shell 吃掉** ✗ ⇒ **远端命令一律写成脚本文件再 scp 执行** ✔。
7. `Python` 往 **GBK 控制台**打印 `✔/⇒/⚠` 会 **UnicodeEncodeError** ✗ ⇒ 输出用 ASCII ✗（T4 探针就栽在这 ✗）。
8. `adb shell` 是 **uid shell** ✗ ⇒ 不能写 `/tmp` ✗、`/data/local/tmp` ✗。
9. **服务进程不要接管道** ✗（`svc | head` ⇒ SIGPIPE 杀服务 ✗）。
10. **误判的教训** ✗：`open/openat` 探针在 bionic 上无效 ✗；"关掉拦截器仍然崩"不等于"拦截器无关" ✗
    （因为**关掉的分支里签名同样错** ✗）⇒ 定位要用**独立探针**（如 `gbmprobe` ✗）而不是只靠 shim ✗。
